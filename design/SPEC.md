### v3.1 指引小人和短弧（取代 v3 长教鞭）
视觉目标：用户新图「词典指引线 修正视觉目标.png」。只参考人物、圆圈、短弧与词条的相对位置，不从图中移用文字或数字。
资产继续使用原始 pointer-hand.png；不重新绘制、缩裁或改写 PNG，不恢复旧 pointer.png。

位置：.term-index 左 padding 为桌面 56px / 手机 44px；右 padding 8px，scrollbar-gutter:stable。
  小人在左留轨内 left:0；显示宽度桌面 40px / 手机 30px。
  脚跟随当前 active row 的底部，不钉容器底。使用实测 active row 与索引容器的 getBoundingClientRect()、滚动偏移及图片脚部比例计算 top；禁止以固定 bottom:8px 替代。
  当图片显示窗口底部有留白时，以原图脚部比例对齐，不能把外框底边误当脚底。

短弧：使用独立 inline SVG 的 path/circle；pointer-events:none，不套 multiply。
  弧线限于左留轨，向左鼓出约弦长的 35%，采用稳定控制点，不在每次重算时随机跳动。
  桌面弧长上限 34px / 手机 22px；原点、终点和控制点均从当前实测位置派生，不跨文字和序号。
  圈的视觉开口改到左下，末端提示圆点采用 slate。
  监听 resize、索引容器 scroll 和 active row 变化后重算；滚动条出现或隐藏不能挤动内容列。

几何边界：原 PNG 的手套位于身体上方，脚对齐 active row 底后，指尖到词圈的实际距离可能超过上述短弧上限。
  本轮按新参考优先实现脚底对齐、人物留轨、线短且不穿字/序号；短弧放在人物侧下方，指向选中词的左侧附近。
  这不等于同时实现「线从原图指尖起，精确连接圈左下开口」；不得拉长线或移动到文字上方来伪装全部约束同时满足。
