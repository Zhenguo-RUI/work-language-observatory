# concise-v1 开发筛查决定

本轮候选停在开发阶段，保留生产 v11。尚未运行候选的10份留出案例，不能声称已经完成跨20例候选评测，也不能把开发组的结果写成留出表现。

候选使开发组两份稀疏输入的中文字段长度由1380降至818、1413降至1023。但10对真实双顺序评审仅2对选择一致，其余8对按预定规则记为平局。计数为候选0胜、8平、2负。20次请求中，16次选择首先呈现的甲、3次选择乙、1次选择平局。这是本轮评审对呈现顺序敏感的证据，不能用这个小样本估计模型普遍的位置偏差，也不能据此证明候选总体更差。

开发组新旧版本的结构、逐字引用和双语检查均为10/10。候选共11次生成请求，包含一次现有恢复调用。生成中位耗时由82.52秒增加至90.68秒，增加9.88%；变短没有直接换来更快生成。留出组候选尚未生成，其硬项、耗时和胜负均未评测，公开JSON以缺失值区分未评测与通过。

本轮不修改评分提示词以求通过，不再调整这个候选，也不据此改动生产代码。应先在之后独立安排的评审校准工作中弄清评分是否把更多例子、纸面材料或社会学段落本身误当成质量，再消耗留出集。当前生成者与评审者都是DeepSeek Flash，独立请求不等于独立知识来源。

下面只记录开发组争议，属于模型评分提出的待核对问题，不能当成已经确认的输出错误。没有公开原文、完整生成内容或评分原句。
