本次只改单篇 JD 分析，不涉及词典、研究页面、UI布局或部署。

## 相对 v10 的变化

- 面试练习的回答思路改为第一人称，每种语言最多三句；使用“我会 / I would”描述做法，不编造申请者已有经验。
- 原文、解释、建议及情境例子的类型继续保存在字段与UI标签中。正文不再重复“假设、建议、待确认”等前缀。必要条件和重要不确定性仍可直接写进句子。
- 删除引出结论或建议的冒号套式、反转排比、重复收尾和升华。字段标签与原文引文不受影响。
- 社会学段只分析，不提供准备建议或以问题结尾。围绕一项原文关系、一个有来源的概念、一个具体适用边界展开，约200中文字、最多250字；找不到贴合概念时整段省略。值得追问的信息放在独立追问区。
- 生成时检查第一人称、三句上限、250字上限和明显的建议/问句收尾。保存结构不变，旧记录不因新增文风规则被拒绝。

## 保留的证据与技术边界

继续使用中英双语；中文只输出的条款不覆盖全站此前的双语要求。原文引文保持原语言，相邻解释提供中文或英文意思，不能把译文当作原文锚点。

不把所有行业写成坐在电脑前的工作。稀疏JD允许减少职责组、准备材料或社会学段，现有JSON所需属性以兼容的空值保留，不为填字段而虚构。

示例只学习具体、简短的表达方式，不照抄固定样本数或经验事实。随机模型输出不能保证每次完全一样；消融必须保留其他条件并停用一项，不能凭一次翻转直接断定原因。一致率不能单独证明标准稳定或正确，实际问题修复和评价标准校准继续区分。

本次没有将12个理论概念整批加入生产。仍只允许已有四项经查核的固定来源：分类与标准、专业工作管辖权、情绪劳动、边界物。例文中的群体分工、劳动负担、阶级意图、考核缺位、雇主动机和工作时间分配均不自动成为事实；一般文档共用也不自动成立边界物分析。

上述检查是窄范围的结构与写法检查，不能替代阅读质量评价，也不能证明理论应用正确。本次另以腾讯评测岗原文和投资岗职责与要求摘录做 DeepSeek 开发回归。发现的错误包括消融操作混淆、从答案臆测隐藏来源，以及把建议表格用作理论证据；失败输出保留在本机，不作为公开范例。少量反复调试的样本不是独立留出评测，也不能用于宣称跨行业准确率。完整公司检索、原JD翻译和用户页面操作另行验收。

## 开发回归后的补充

- 分类分析只在原文明示实质类别或评价标准时触发。普通归档、核对数字和规范格式不足以触发；这一操作门槛不是对分类理论适用范围的概括。
- 社会学分析只能用原JD所述的事项与材料作依据，不能把前文建议制作的表格反过来当作公司事实。
- 学历及在读身份保留原意，不能将“硕士研究生优先”改称分析训练。新增的资格检查仅用于新生成结果，已有记录仍能读取。
