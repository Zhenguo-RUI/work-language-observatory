# PDF export font

Noto Sans SC Regular is bundled for on-device PDF generation. It is loaded only when a reader requests a PDF, then embedded in the PDF so Chinese remains legible on other devices. Submitted JD text is not sent to a font or PDF service.

- Typeface: Noto Sans SC, Regular (400)
- Official Google Fonts stylesheet: https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400
- Official binary: https://fonts.gstatic.com/s/notosanssc/v41/k3kCo84MPvpLmixcA63oeAL7Iqp5IZJF9bmaG9_FnYw.ttf
- Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc
